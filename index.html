My Projects

Amazon Sales Analysis

This project analyzes Amazon product sales and customer engagement using Power BI. The data was cleaned and transformed to build an interactive dashboard that highlights product performance, pricing, discounts, ratings, and customer engagement. Tools Used: Microsoft Excel, Power Query, Power BI, DAX. Key Insights: Electronics had the highest review volume, Office Products recorded the highest average rating, Amazon-branded products received greater customer engagement than third-party brands, and price and discounts showed only a weak relationship with customer ratings.

Hotel Booking Analysis

An end-to-end hotel booking analysis using Excel for data cleaning and Power BI for interactive dashboard visualization. Tools: Microsoft Excel, Power BI (Power Query, DAX). Key Insights: Portugal had the most bookings, the average stay was 3.43 nights, the average ADR was 101.83, City Hotel generated more revenue but had more cancellations, and August was the busiest booking month.

Investment Preference Analysis

This project analyzes investor survey data to uncover investment preferences, decision-making factors, and financial goals through an interactive Power BI dashboard. **Tools:** Excel, Power Query, Power BI, and DAX. **Key Insights:** PPF and Mutual Funds were the most preferred investment options, retirement planning was the top savings objective, and expected returns were the primary factor influencing investment decisions.

Women's Clothing E-Commerce Review Analysis

This project analyzes women's clothing e-commerce reviews using Excel and Power BI to uncover customer satisfaction, product performance, and recommendation trends. Key insights include an 82.2% recommendation rate, Tops receiving the most reviews, and the Trend department showing the greatest need for improvement.
